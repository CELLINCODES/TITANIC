# TITANIC

Aplicação com o intuito de mostrar meu aprendizado a cerca de limpeza de dados, a aplicação visa obter os dados com base no csv

## Tecnologias utilizadas

* Jupyter
* Pandas
 

## Funcionalidades

* Limpeza de dados
* Leitura de arquivos CSV
* Exibição de dados processados

## Objetivo

Projeto criado para praticar conceitos de análise e limpeza de dados, permitindo transformar informações brutas em dados mais organizados e utilizáveis.
